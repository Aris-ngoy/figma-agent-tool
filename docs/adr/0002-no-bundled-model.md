# No bundled model: the user's Agent does the designing

Unlike Stitch, which generates screens with its own Gemini model, this tool ships no model, API keys or prompts. The user's own Agent does the design thinking; the tool gives it a Design Project, a design system, a preview and Figma. That keeps it agent-neutral and free of provider costs, at the price of design quality depending on the Agent and on the guidance the tool gives it.
