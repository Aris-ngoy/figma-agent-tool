# One npm package, bundled for Node, with a skill it installs

`figma-agent-tool` is the one published package: `packages/mcp-server`, whose single bin runs the CLI, the Preview and (`mcp`) the MCP server. Its build bundles every workspace package and dependency into one file for Node (`bun build --target node`), so `npx figma-agent-tool` works without Bun. The code therefore uses only Node APIs at runtime: the plugin bridge is `node:http` with `ws`, the Preview `node:http`, Render `node:child_process`. Bun stays the repo's package manager and test runner. Only `@google/design.md` is left as a runtime dependency, because it reads its spec from a file next to its own code. CI packs the tarball and runs it with `npx` on Node LTS with Bun off the PATH.

The agent guidance lives in one place, `skill/SKILL.md`, shipped in the package and installed with `figma-agent-tool skill` (into `.claude/skills/` by default, or `--into` another harness's folder). The MCP server's instructions are a short version of it, for clients that don't load skills. A test checks that the skill's example files pass Check and that it names every Design Project tool, so it can't drift from the Screen Subset.
