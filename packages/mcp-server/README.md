# figma-agent-tool

Lets any coding agent design UI as files in your repo, preview it, and sync it with Figma both ways.

```sh
claude mcp add figma-agent-tool -- npx -y figma-agent-tool mcp   # the MCP server
npx figma-agent-tool skill                                        # the agent skill
npx figma-agent-tool --help                                       # the CLI
```

You also need the Figma plugin. See the [README](https://github.com/Aris-ngoy/figma-agent-tool#readme) for setup and the workflow.
